My book, Software Engineering in the Agentic Era: How one engineer and a fleet of AI agents ship real software, is now on Gumroad as a download: https://chovyfu.gumroad.com/l/softwareengineering

Code got cheap. Judgment did not. The book is the field guide I wish I had when we started running about 170 repositories with a handful of humans and a fleet of AI agents. It covers how work gets framed, fanned out, checked, shipped, secured, paid for and announced when typing is no longer the bottleneck.

What is inside

  • The Shift: the bottleneck moved, one engineer with a fleet, and how agents fail.
  • The Workbench: the terminal is back, browsers agents can drive, pairing with humans and agents.
  • The Loop: frame, fan out, gate. Review is the job. Ship everywhere.
  • Running the Fleet: keys, vaults and blast radius, money for machines, identity for agents.
  • The People: careers in the agentic era, and the playbook.

Plus a toolbox appendix with the install command for every tool in it.
