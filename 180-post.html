How this was written: drafted with an AI assistant from my own notes, then edited by me.

readm3.com can now hand out a private link for a Markdown document without anyone signing in. Paste the file, pick how long the link lives, and you get https://readm3.com/p/<token>. Anyone with the link reads the document in the web reader. Nobody can list it, search for it, or ask the server for the link again, because only the hash of the secret is stored.

It is for handing a document to someone, not for keeping one. A paste expires after seven days by default, an hour to thirty days if you choose, is limited to 256 KB, and can be deleted by whoever holds the link. Signed-in users still have the full thing: saved documents, versions, editors and share links that can be revoked.

From the terminal

readm3 paste notes.md cat notes.md | readm3 paste --expires 1d --title "Standup" readm3 paste get https://readm3.com/p/... --raw readm3 paste delete https://readm3.com/p/...

readm3 paste prints the URL and nothing else, so it drops into a script. --json prints the whole answer.

From the browser, the API and an agent

Signed out, the Share button in the web reader offers the private link instead of a sign-in wall. Opening a /p/ link shows the document read-only with its expiry and a Delete link button.

The API is three calls: POST /api/v1/pastes with the Markdown, GET /api/v1/pastes/<token> and DELETE /api/v1/pastes/<token>. An agent gets the same three as the paste_create, paste_get and paste_delete MCP tools, and readm3 mcp serves them over stdio.

Also new in this release: https://readm3.com/viewer?url=<raw Markdown URL> opens a public document straight into the reader. That is the link every page on fleetsysops.com carries.

npm install -g @profullstack/readm3

Docs: https://readm3.com/sharing. Source: https://github.com/profullstack/readm3.
