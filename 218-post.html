pwamart: an app store for web apps

How this was written: drafted with an AI assistant from my own notes, then edited by me.

Progressive Web Apps install like native apps on every platform that matters, but there has never been a good place to find them. The app stores do not list them, and the ones that do want a review queue and a cut. So we built one: pwamart.com.

pwamart lists installable web apps and installs them on iPhone, Android, Mac, Windows and Linux. No review queue, no 30% cut, nothing to root or jailbreak.

The Install button

A store cannot press another site's install button, so the details page does the most each browser allows:

  • Chrome and Edge with the Web Install API: one click, the browser installs it.
  • Android: open it and confirm, and it lands in the app drawer.
  • iPhone and iPad: the two taps in Safari, or a one-tap profile that puts the icon on the Home Screen from Settings.
  • TronBrowser: the app opens in its own TronBrowser window, with the launcher's settings.
  • Safari and Firefox on desktop: the exact steps for that browser.

Every surface

  • Web and PWA: the store itself installs as an app.
  • CLI: npx -y @profullstack/pwamart search notes, then pwamart install <slug> opens it as an app window and adds a launcher entry.
  • TUI: pwamart tui is the whole store in a terminal, built on hqtui.
  • MCP: claude mcp add pwamart -- npx -y @profullstack/pwamart-mcp, or the hosted endpoint at https://pwamart.com/mcp. Agents can search, read listings and get install steps for any platform.
  • API: https://pwamart.com/api/v1, documented in llms.txt.
  • Desktop: pwamart Desktop for Mac, Windows and Linux installs any listing as its own window with its own storage.

Publishing

Paste your app's URL. pwamart reads the manifest, grades installability (HTTPS, icons, display mode, start URL, service worker, screenshots), and builds the listing. Prove you own the domain with a file, a meta tag or a DNS record, then publish.

Pricing is per account, paid yearly through CoinPay:

  • Free: 1 publisher, 10 apps
  • Pro, $10 a year: 10 publishers, 100 apps
  • Unlimited, $199 a year: no limits, plus shared orgs, teams and projects

Installing is always free, and pwamart never takes a cut of what your app sells.
