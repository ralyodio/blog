watch.wallet: know the second your wallet moves

If a wallet you never touch suddenly sends funds, you want to know right then, not when you happen to open an explorer. Most wallet apps only watch the wallets you hold in them, and a push you sleep through is a push you didn't get.

So I built watch.wallet.

What it does

  • Watch an address on Bitcoin, Ethereum, Base, Polygon or Solana. It reads the native coin plus USDC and USDT, and tells you when any of them changes. On Bitcoin a transaction counts the moment it hits the mempool.
  • Watch a price. BTC above $100k, SOL below $120. It fires once, then re-arms when the price crosses back.
  • Only big moves, if you like: set a dollar threshold so dust doesn't page you.

Alerts come by email and web push for everyone. On the Watcher plan they can also come as a phone call ("press 1 to acknowledge") and a signed webhook for your own bots and agents.

The rules it keeps

  • A failed read never alerts and never moves the baseline. Public RPCs fail all the time; that should not look like your wallet emptied.
  • Each move alerts once, even with two workers racing.
  • A lapsed plan never deletes anything. Extra watches pause until you renew; the first three keep running.

Free lookup

watch.wallet.pit.world/check shows any address's balance on any of the five chains, no sign-in.

For the terminal and for agents

npx @profullstack/watchwallet check bitcoin bc1q…
npx @profullstack/watchwallet add ethereum 0x… --label "cold wallet" --min-usd 100
npx @profullstack/watchwallet price BTC above 100000
claude mcp add watchwallet -- npx @profullstack/watchwallet mcp

There is a JSON API too, and check_address in the MCP server needs no key at all.

Price
