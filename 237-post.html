W3BS Training: teach agents by doing the task yourself

2026-10-16, by Anthony “chovy” Ettinger.

How this was written: drafted with an AI assistant from my own notes, then edited by me.

Agents are bad at the tasks only you know how to do: your release checklist, your expense report, the three windows you open in a certain order. W3BS Training lets you show them once and decide exactly who gets to learn from it.

How it works

  1. Record. In the Agentic Desktop Layer tray, choose Start training…, say what you are about to do and tick the apps it may see. It keeps pictures of those apps' focused window only. An unapproved window in front, or overlapping, is a gap, never a frame. No keystrokes, typed text, clipboard or audio.
  2. Review. Each recording is a task card: confirm the goal, say how it went, clear privacy warnings. Nothing is used until you review it.
  3. Share with one agent. Freeze reviewed tasks into a dataset version, approve it for a purpose (private retrieval does not approve model training) and grant a named agent. It retrieves examples over MCP as evidence, never as instructions.
  4. Check it helped. Agents report each attempt with and without the examples, and the app compares the two with confidence intervals instead of claims.

Local first, hosted when you want it

w3bs training open runs the review app on your machine, from a one-time link, with frames encrypted (AES-256-GCM) by a key in your keyring. When you want your tasks on another device, or a hosted agent to use them, w3bs training push sends reviewed tasks to your own workspace at w3bs.org/training/app. Each account gets its own database schema there. The server can decrypt what you push, and the docs say so plainly.

Everything uses one open format, the W3BS Demonstration Dataset Format 0.1, so you can export a bundle, a JSONL dataset or next-action training examples and take them anywhere.

Honest limits

Recording is verified on KDE Plasma; GNOME, Windows and macOS share the code but have not been through the test rig. Wayland has no passive input tap, so recordings are screenshots of approved windows: they show an agent how a task is done, but they are not action-level training data. There is no model-training integration yet.

Try it

curl -fsSL https://w3bs.org/training/install.sh | sh

Or w3bs install w3bs-training. On Linux, also install libsecret's secret-tool (sudo apt install libsecret-tools on Debian and Ubuntu) so the encryption key lives in your desktop keyring; without a keyring it refuses to store recordings. Recording needs the Agentic Desktop Layer. More at w3bs.org/training.
