profullstack.com stopped calling itself a web development agency today. The title, the meta tags, the home page, the services list and the skill.md that agents install all say the same thing now: Profullstack is an agentic engineering firm.

What that means

One senior engineer directs a fleet of coding agents on a codebase. The agents write most of the code. The engineer decides what gets merged, and every change goes through review, tests and CI before it ships. That is how we have run our own 170 or so active repos for months, and it is how we work on client codebases.

The pricing page already said this. profullstack.com/plans has billed per agent hour since late August, with a senior engineer supervising each active agent. The rest of the site was still selling "custom websites built with modern frameworks", which is a description of 2019. The site now matches the work.

Who it is for

Funded teams that need a product built at agent speed without cutting corners. Teams whose engineers are trying Claude Code or Codex and getting uneven results. Businesses replacing a cheap build that breaks, who want a fractional CTO to rebuild it right.

What changed on the site

  • The page title is "Profullstack, Inc. | Agentic Engineering", with a title template for every child page. The description, keywords, Open Graph and Twitter cards say the same, and an Organization JSON-LD block carries it to search engines.
  • The home page hero, the audience cards and the about section were rewritten. A new card covers teams adopting agents.
  • The services list leads with agentic engineering, agent enablement (skills, MCP servers, guardrails and review loops for your own team), AI and LLM systems, and the $8,000 fixed-price security audit. Web and app development are folded into full-stack product engineering.
  • skill.md, the file you install into Claude Code or Codex, describes the model in its first section.

How to use it

Read the site at profullstack.com. If you want agents on your codebase, book the free 30 minute diagnostic at profullstack.com/book. If you want your own agents to build the way we do, install the skill from profullstack.com/agents.

The change shipped as profullstack-web PR #37.
