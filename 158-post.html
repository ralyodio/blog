OpenMCP is live: a browsable catalog of MCP relays, and a headless browser it hosts

2026-09-16, by Anthony “chovy” Ettinger.

Every product that speaks MCP is a relay: an endpoint an agent can call over HTTP. Until now each one was found by hand, from a README, and wired into a client's config by a person. OpenMCP is a catalog that lists relays it has actually reached, and it is running at openmcp.logicsrc.com.

What a relay does to be listed

It serves one file, /.well-known/openmcp.json, saying where its MCP endpoint is, how to authenticate, what it is for and who operates it. The catalog probes before it lists: the descriptor from the relay's own origin, then an MCP handshake and tools/list. What is listed is what the probe found, never what somebody typed into a form. A relay that serves the file is marked verified; one that answered the handshake is marked online; both facts are shown, and they are the only two the catalog asserts.

A catalog is itself a relay. Its MCP endpoint offers list_relays, find_tool and call_tool, so an agent that can reach one catalog can reach every relay in it, and pass its own credential for the relay through without the catalog keeping it.

New today: a directory for people

The same records are now a web page. openmcp.logicsrc.com in a browser is the directory: search, filter by tag, open a relay to read its tools and their schemas. An agent asking the same URL with an Accept: application/json header gets the JSON index it always did.

Sign-in is an emailed link and nothing else. It doubles as registration: an unknown address makes the account rather than being turned away, and the answer to "send me a link" is the same whether or not the address is known, so the endpoint cannot be used to list who has registered. Once signed in, a relay you register is yours: probe it again whenever you like, or remove it. Relays registered anonymously stay unowned and stay listed.

New today: Obscura, hosted by the catalog

A catalog can now run a relay inside its own process. The first one is Obscura, a headless browser written in Rust with a real V8 and Chrome's TLS fingerprint. It is listed at obscura.openmcp.logicsrc.com, verified and online like any other relay, with one tool: fetch_page takes a URL and returns the page as markdown, plain text, its links, the rendered HTML, or the original bytes.

The reason it exists is that a lot of the public web now answers a plain HTTP client with 403. The CDC's Health Alert Network page and its MMWR feed do; curl gets nothing, and this relay returns the page in about a second and a half. No key, no account, three fetches at a time, a minute each at most, public hosts only.

From any MCP client, through the catalog:

curl -X POST https://openmcp.logicsrc.com/v1/relays/obscura.openmcp.logicsrc.com/call \ -H 'content-type: application/json' \ -d '{"tool":"fetch_page","arguments":{"url":"https://www.cdc.gov/han/","format":"text"}}'

Or direct, at https://obscura.openmcp.logicsrc.com/mcp.

Run your own

The reference catalog is npx @logicsrc/openmcp serve: Node 24, one SQLite file, no build step. OPENMCP_HOSTED=obscura turns on the hosted browser relay when the obscura binary is on the path. The specification is at logicsrc.com/openmcp and the code is MIT at github.com/logicsrc/openmcp.

To be listed, serve the file. npx @logicsrc/openmcp descriptor https://your.site/mcp prints one to start from.
