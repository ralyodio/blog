Sign your releases with the SSH key you already have

W3BS packages can now be signed by their publishers, and the signature is made with plain OpenSSH. No new tool, no certificate authority, no key type you have to learn.

Why

Most developer tools install with curl -fsSL https://example.com/install.sh | sh. The W3BS registry already signs its catalog, so you know the listing came from w3bs.org. What it could not tell you is whether the installer is the one the publisher meant to ship. Now it can.

How it works

  1. Register a key for your domain. w3bs publish key add example.com signs a challenge with ~/.ssh/id_ed25519 and prints one line to publish at https://example.com/.well-known/w3bs-publisher.txt or as a TXT record on _w3bs.example.com. Proving the domain makes your account its publisher.
  2. Publish a release. w3bs publish release --package example.com/tool --version 1.2.0 --install "curl -fsSL https://example.com/install.sh | sh" downloads your installer, records its sha256 in a small JSON statement and signs it with ssh-keygen -Y sign -n w3bs-release@w3bs.org.
  3. Install it. w3bs install example.com/tool checks the signature, pins your key for your domain, and refuses to run an installer whose sha256 does not match what you signed. A later release signed by a different key, or with the signature stripped, is refused unless the user accepts it.

Ed25519 and ECDSA keys work, including hardware FIDO keys. The signature namespace means a git commit signature can never be replayed as a release.

Check it without trusting us

Every signed package page shows the commands to verify the release offline with ssh-keygen -Y verify. The registry also re-verifies every signature before it lands in the catalog, so a compromised web server cannot add one.

First up: the hqtui demo, in 11 languages

The hqtui ten-screen terminal dashboard is now on w3bs.org/packages once per language: TypeScript, Rust, Go, Python, Zig, C++, Ruby, PHP, Perl, Nim and COBOL, each signed by hqtui.com.

curl -fsSL https://w3bs.org/install.sh | sh
w3bs install hqtui.com/hqtui-demo-rust
hqtui-demo-rust --sim

Publish yours: w3bs.org/packages/publish. The format is an open draft, W3BS-SIGN-1.
