What a domain costs in year two

2026-09-28, by Anthony “chovy” Ettinger.

How this was written: drafted with an AI assistant from my own notes, then edited by me.

back to my blog postings

The price on a registrar's front page is the first year. The number that matters is the renewal, and on a lot of top-level domains it is a different number entirely. A .watches name is $52 to register at Porkbun and $258 a year after that. A .baby is $1.54, then $50.20.

So nichedb.dev now has /tlds: every top-level domain in IANA's root, with each registrar's price to register, renew, transfer and restore beside it, sorted by the renewal.

What is in it

  • The list, diffed daily. IANA publishes the list of top-level domains every day as a text file. Nobody publishes what changed between two days, so nichedb keeps it as a table and writes every label that appears or disappears to a change log. The 157 labels IANA has retired are in there too.
  • Type and registry from IANA's root zone database, and the RDAP server for each label from its bootstrap file.
  • Prices from Porkbun, Dynadot, Cloudflare (at cost) and OVHcloud, read daily. Currencies are never converted: OVH is in euros, and Dynadot's page switched from dollars to yuan between two reads from the same machine, so it is stored in whatever currency it answered in.
  • Facets for type, renewal band, registrar, script, status and registry, and a filter for the renewal trap: about 300 labels renew at twice the first year or more.
  • Is a name taken? /tlds/check asks each registry over RDAP. A 404 means the registry holds no registration, which is not the same as for sale, so it says "not registered" and never "available". Where a registry runs no RDAP server (.io and .de among them) the answer is unknown.

The same rows everywhere

GET /api/v1/tlds (JSON with facet counts, or CSV), MCP tools (search_tlds, get_tld, tld_changes, check_domain) and the CLI:

npx @profullstack/nichedb tlds --trap --sort ratio --order desc
npx @profullstack/nichedb check myproject --tlds com,dev,watches

OpenTLD

The shape of a price and of a top-level domain record is written down as OpenTLD. A registrar that serves its price list at /.well-known/opentld.json gets read directly, with no scraping, and stays the author of its own numbers. The one rule it insists on: if you state the first year, state the renewal.
