pwamart: every app is a PWA, CLI, API or MCP, and collections install in one command

2026-10-19, by Anthony “chovy” Ettinger.

How this was written: drafted with an AI assistant from my own notes, then edited by me.

pwamart.com started as an app store for PWAs. Most of the apps we list are more than a web page, though. Many ship a CLI, an HTTP API or an MCP server too, and an agent would rather use those than click through a browser.

So every listing on pwamart now says which of the four it is: PWA, CLI, API, MCP. Each one it has comes with copy-paste instructions on the app page.

  • CLI: the publisher's own curl -fsSL https://the.app/install.sh | sh. If the tool is in the w3bs package catalog, you also get w3bs install host/name, which keeps it current with w3bs update.
  • MCP: a claude mcp add --transport http … line, the npx stdio command when there is one, and an mcpServers block for Claude Desktop or Cursor.
  • API: the base URL and a link to the OpenAPI spec or llms.txt, so an agent can read the docs itself.

Nobody fills in a form. Once a week the store looks at each app's own site for a shell script at /install.sh, an MCP server that answers initialize at /mcp or /api/mcp (or wherever its llms.txt says), and an OpenAPI file or documented /api/ routes. A 200 is not enough: an SPA answers every path with its HTML shell, so the script needs a #! and the MCP server has to actually reply. Publishers can correct anything with pwamart surfaces <slug>.

The first sweep of 431 listings found 39 CLIs, 80 APIs and 51 MCP servers, and it is still going.

Collections

The other half is collections, borrowed from bundl.run's idea of installing a whole workflow at once, but for agents instead of Mac apps. There are six workflows (agentic coding, agents that get paid, ops and security, growth, research, talking to humans), plus every MCP server, every CLI and every API.

Each collection installs in one line:

curl -fsSL https://pwamart.com/collections/agentic-coding/install.sh | sh

That script runs each app's own installer in turn and keeps going if one fails. The same page gives you every MCP server as claude mcp add lines or one mcp.json, and an iPhone profile that adds every app to the home screen. Untick an app and the commands drop it.

Agents get it too: GET /api/v1/collections, the MCP tools list_collections and get_collection, and pwamart collections in the CLI (0.7.0).

If you have a PWA with a CLI or an MCP server, list it free and it shows up in the right collection on its own.
