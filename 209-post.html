myna now has a dashboard for the posts only you can make

2026-10-02, by Anthony “chovy” Ettinger.

How this was written: drafted with an AI assistant from my own notes, then edited by me.

back to my blog postings

myna posts to Bluesky, Mastodon, LinkedIn and the rest on its own. Some places it can't post to: Hacker News has no write API, a subreddit wants a human, and X is off for us. For those, myna writes a hand-off card. The card holds the exact text, the page to paste it into and a button to mark it done.

Until today, to see those cards you ran myna handoff list in a terminal, or opened each card's own link. Now they are all in one place:

https://mynaposter.com/dashboard

What you see

Sign in with your myna cloud account, the same one myna cloud login uses. The page lists every open card, newest first, with its place, its title and when it was made. Tap one to open it and you get:

  • the text, with a Copy button
  • Open reddit.com (or wherever the card goes), so the paste target is one tap away
  • Mark done, which the CLI sees too
  • a link to the card's own page

Show done brings back the finished cards, each with Undo. It works on a phone, which is where I actually use it: myna makes the cards from the terminal, and I paste them from the couch.

How the sign-in works

It uses the same email and password as the CLI. The server sets the session as an HttpOnly cookie, so the page's JavaScript never sees the token, and the cookie only works on reads. Every write in the API still needs the bearer token the CLI sends. Marking a card done needs no sign-in at all, because the card's link is its permission. Magic link and passkey sign-in are next.

myna handoff list now prints the dashboard link when you are signed in. Update with myna update to get 0.40.0.

Your post queue isn't on the dashboard. It stays on the machine that sends it, and myna queue still shows it.
