Code got cheap. Judgment did not.

We run about 170 repositories with a handful of humans and a fleet of AI coding agents. Today we are publishing what that taught us as a free book: Software Engineering in the Agentic Era: How one engineer and a fleet of AI agents ship real software.

!Cover of Software Engineering in the Agentic Era

What is in it

  • The Shift. Where the bottleneck went once typing stopped being expensive, what a team looks like when one engineer directs a fleet, and nine specific ways agents fail (each one became a house rule).
  • The Workbench. The terminal is back, agents need a real browser, pairing needs a seat for the agent, and your stack has to be written down where agents can read it.
  • The Loop. Frame, fan out, gate. Review is the job. Ship everywhere. Then tell somebody.
  • Running the Fleet. Keys and blast radius, money for machines with x402, identity for agents, compute on tap.
  • The People. Careers in the agentic era and a playbook of checklists you can use on Monday.

Along the way you will meet the tools we built for this way of working: moshcode, TronBrowser, PairUX, hqtui, sh1pt, ThreatCrush, CoinPay, myna and more, each with its install command.

Free, and open source

Get the PDF, EPUB or HTML at profullstack.com/book. The Markdown source is on GitHub at profullstack/agentic-era-book under CC BY-SA 4.0, built with pandoc. Found a stale command or a better way? Send a pull request.
