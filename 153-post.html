This AI-generated infographic maps the tools around Chovy: the agent interface, the scripts that connect work, the development environment, and the services that publish and support a product.

!Infographic of the Chovy tool stack: agent interfaces connect through MoshCode and MoshScript to a development environment and tools for publishing, audience discovery and payments.

At the top is the choice of interface. Chovy is the place to describe an app and review the result. MoshCode puts the agent sessions and tools in a terminal. MoshScript connects commands into repeatable JavaScript workflows.

Under those interfaces is a working development environment: repositories, Git, a runtime, and the tools the project needs. The interesting work happens when a script can connect a change in that repository to a checked result.

The bottom of the map shows the services we use around the product. Myna handles publishing and scheduled posts. OutreachGraph helps discover and organize prospective customers. CrawlProof measures traffic and distributes ads. CoinPay supplies crypto checkout and payment workflows.

The picture is a map of the stack and its direction. The product pages linked above carry the current features and commercial terms. MoshScript's examples on its site are executable JavaScript; the small script in the picture illustrates a workflow.
