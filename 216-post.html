d0rz is a local help marketplace. Neighbors post asks, things they need done like a ride to an appointment, a prescription pickup or a dog walk, and offers, things they can do. Until today you could only use it in a browser. Now you can use it from code, a terminal or an AI agent.

The API

Everything you can do on the site is at https://d0rz.com/api/v1: browse and search asks and offers, post your own, respond, accept a response, and message. Make a key on your account page and send it as a Bearer token.

curl "https://d0rz.com/api/v1/asks?category=errands" \
  -H "Authorization: Bearer d0rz_key_..."

A key acts as you, and the database's row-level security decides what it can see and change, exactly as it does for your browser session. There is no second permission system to drift out of step. The full OpenAPI 3.1 spec is at d0rz.com/api/v1/openapi.json and the docs are at d0rz.com/docs/api.

The CLI

npx @profullstack/d0rz login
d0rz asks list --city Oakland
d0rz offers create --title "Dog walking" --body "Two walks a day, Rockridge" --category pet --rate 20 --rate-unit visit
d0rz responses accept <id>

d0rz login opens your browser and signs the CLI in with OAuth 2.1 and PKCE. The refresh token rotates every time it is used, and reusing an old one signs that login out. Over SSH, d0rz login --no-browser shows a code you paste back in. Add --json to anything for scripts.

d0rz tui is a live board of open asks, offers and your inbox, refreshed every 30 seconds.

The MCP server

d0rz mcp exposes every API operation as a tool, 32 of them, using the CLI's sign-in:

claude mcp add d0rz -- npx -y @profullstack/d0rz mcp

Then ask your agent to find someone to help move a couch on Saturday, or to answer the pet sitting asks near you.

The package is @profullstack/d0rz on npm, MIT licensed.
