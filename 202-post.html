PairUX 0.10.0: booking links, calendar invites, and a toll gate for AI crawlers

PairUX 0.10.0 is out. It is the first minor bump since the 0.9 series, and it carries nineteen changes across the web app, the desktop builds and mobile.

Booking links

You can now hand someone a link and let them pick a time. A booking page lives at /book/<username>/<slug>, shows the slots you actually have free in the visitor's own timezone, and books the call. The part that matters is what happens next: the meeting is a PairUX room, not a calendar entry pointing at some other product. Whoever books lands in the same screen share and pairing session you would have sent them manually.

Every meeting email carries the calendar

Invites, updates and reminders now go out with add-to-calendar links and an .ics attachment. Google, Outlook and anything that reads an ics file get the same event, with the join URL inside it. Before this, a reminder email told you a meeting was coming and left you to make the calendar entry yourself.

Channels show what is live

The /channels directory now counts live sessions and recordings per channel, so an empty channel reads as empty and a busy one reads as busy. Small change, but the directory was previously a wall of names with no signal about which of them anyone was using.

A toll gate for AI crawlers

PairUX now runs the x402 gateway in front of its content. An AI training crawler that wants the pages can pay for them; a reader browsing normally is unaffected. Blog pages also ship with a CrawlProof unit by default, and the site serves an OpenAccess descriptor at /.well-known/openaccess.json so an agent can find the terms without guessing.

Desktop and mobile

The desktop app got P2P relay and media lifecycle parity with the web client, which fixes the cases where a peer-to-peer call on desktop behaved differently from the same call in a browser. Group call audio and negotiation stay in sync through a reconnect now, and a viewer who denies microphone access gets a recoverable prompt instead of a dead call. On mobile, chat drafts survive a backgrounded app, session refresh is bounded so a reconnect can actually finish, and Android screen share startup is hardened.

Next.js is updated to clear a set of critical security advisories.

Getting it

Desktop builds are published for macOS (Intel and Apple Silicon), Linux (x64 and arm64) and Windows, and the package manager repos are updated: Homebrew, Scoop, Chocolatey, apt, rpm, Nix and Gentoo.

Release notes and downloads: https://github.com/profullstack/pairux.com/releases/tag/v0.10.0

The web app is live at https://pairux.com
