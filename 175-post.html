fleetsysops.com: a manifesto for running a fleet of coding agents

2026-09-22, by Anthony “chovy” Ettinger.

How this was written: drafted with an AI assistant from my own notes, then edited by me.

back to my blog postings

A fleet is agents. Dozens of them at once, coding, deploying, posting and fixing, on servers they have root on. A sysop is the one human running the fleet. Some call it fleet coding. Today we wrote down how we do it, and put it at https://fleetsysops.com/manifesto.md. It is short and it is blunt:

  • We test in prod.
  • We build in prod.
  • We code in prod.
  • Root everywhere.
  • No Kubernetes. No cloud shit.
  • --yolo mode enabled.
  • We scale when we need to.
  • Everything ships with a TUI, a CLI, an MCP and an API.
  • We are the moat.

Half of it is a joke and all of it is true. An agent that has to ask permission for every step is a chat window. An agent's work is done when it is live and verified there, not when a test passed on a laptop. More agents when there is more work, more boxes when one falls over, nothing predicted. There is no model or cloud account a competitor cannot buy tomorrow; what they cannot buy is the sysop and the fleet, so we are the moat. And the sysop's job is not to write the code. It is to pick the work, read what came back, kill what went wrong and merge what did not.

A site that is only Markdown

The site follows the same attitude. Every page on fleetsysops.com is a Markdown file in a public repo and nothing else. No HTML, no JavaScript, no build step. The home page is index.md. A missing page is 404.md, served with a 404.

A browser gets the source as plain text, so you read it the way it was written. curl gets text/markdown. An agent gets the same file a human does. The whole server is ninety lines and every response allows any origin, so any reader can fetch a page.

The html link

Each page ends with one small concession: an html link. It hands the file to readm3.com, our Markdown reader, which renders it in the browser. That needed one addition to readm3: https://readm3.com/viewer?url=<a raw Markdown URL> now opens that document straight into the workspace, the same path the Open URL dialog takes. Any site that publishes plain Markdown can put that link on its pages.

curl https://fleetsysops.com/manifesto.md curl -s https://fleetsysops.com/manifesto.md | npx @profullstack/readm3 --print

More documents for the sysop will land on fleetsysops.com as we write them. The repo is at https://github.com/profullstack/fleetsysops.com and the reader is at https://readm3.com.
