wx93.me is a URL shortener built for agents as much as people. It launched today, with 9xq.me as a second short domain on the same links.

What it does

Shorten a link and every code works on both hosts: wx93.me/j9qkr4 and 9xq.me/j9qkr4 go to the same place.

Redirects are plain HTTP. No JavaScript, no tracking pixel page, nothing for a script to execute. A bot, a link preview or curl gets the 302 straight away.

Free links show a 5 second ad page to people first. It is server rendered with a meta refresh and a Continue link, so it works with JavaScript off. Crawlers and unfurlers skip it, so previews in Slack and Discord still look right.

Every surface

  • Web app, also installable as a PWA
  • REST API at /api/v1, with API keys
  • CLI with a terminal UI: curl -fsSL https://wx93.me/install | sh
  • MCP server, hosted at wx93.me/mcp or local with npx -y @profullstack/wx93-mcp
  • Desktop app with the CLI inside, on the v0.1.0 release
  • /llms.txt for agents that read before they act

Paying for it

Crypto only, through CoinPay. No cards.

  • Free: 100 links a month with an account, ad page on
  • Pro: $5/month or $50/year. No ad page, custom aliases, full stats, API keys
  • Automation: $29/month or $290/year. Bulk create, signed webhooks, custom domains, 100,000 links a month

Agents without an account can pay per use over x402: $0.25 buys a 60 minute pass for 100 ad-free links.

Abuse

New links are checked against URLhaus and OpenPhish feeds, creation is rate limited, and any link can be reported.
